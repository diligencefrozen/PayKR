# v0.2.2 GPS / 전체 검색 수정
이 패치는 v0.2 변경사항을 모두 포함합니다. v0.1 또는 v0.2에 덮어쓸 수 있습니다.
- 첫 접속 시 GPS 조회 후 검색, 실패 시 원주 기본 위치에서 검색. 지도 초기 표시 자체는 원주입니다.
- 전체 선택 시 현재 지도 중심 및 확대 수준 유지, 기존 내 주변 검색의 배치 순회 재사용.
- 카카오 모드에서도 전체 브랜드 165개 검색. 카카오 API의 결과 및 쿼터 제한은 유지.
- DB 모드 최대 600개 자동 조회 후 더 보기 제공.
- 가맹점 수집, SQL, Secrets, DB 활성화 설정 변경 없음.
- node scripts/check.mjs 통과 (브라우저 실환경 테스트 미실시).
