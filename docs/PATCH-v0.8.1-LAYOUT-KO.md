# PayKR v0.8.1 상세 화면 레이아웃 패치

v0.8 커뮤니티 패치 적용 후 덮어쓰는 증분 패치입니다. 압축 파일 내부의 상대 경로를 유지하세요. GitHub Desktop에서 변경 파일을 확인하고 커밋·푸시하세요. 이미 별도 수정한 파일은 덮어쓰기 전 비교하세요.

- PC(769px 이상): 왼쪽 검색/목록, 중앙 독립 가맹점 상세, 오른쪽 지도 영역. 목록과 상세가 따로 스크롤됩니다. 상세 상단 제목과 닫기 버튼을 유지합니다. 상세를 닫으면 지도 공간을 다시 활용합니다.
- 모바일: 기존 하단 시트/마커 상세 모달 유지.
- 결제 성공/실패, 댓글, 오류 제보 영역이 보이되 미연결 가맹점과 미배포 API에서는 버튼을 비활성화하고 이유를 표시합니다. 실제 가맹점별 수치가 없을 때 임의로 표시하지 않습니다.
- DB 설정과 Worker 코드는 건드리지 않았습니다. Kakao 검색 가맹점의 제보 활성화에는 안정적인 가맹점 식별/검증과 서버 연동이 필요합니다. 공공데이터 모드와 API 주소 설정도 아직 별도 작업입니다. 운영 API 주소를 이미 수정했다면 이 패치 적용 후 `node scripts/pwa-assets.mjs`로 자산 목록을 다시 생성하세요.
- `node scripts/check.mjs` 통과. Chromium 통합 화면 테스트는 실행 환경의 페이지 접근 차단(ERR_BLOCKED_BY_ADMINISTRATOR)으로 완료하지 못했습니다. 실제 운영 화면/DB 테스트는 미실시입니다.
- 적용 후 GitHub Pages 배포 완료 확인, Ctrl+Shift+R, 시크릿 창 등으로 확인. 910px/1280px PC와 390px 모바일에서 목록, 상세 닫기, 스크롤, 지도 클릭을 확인하세요.
