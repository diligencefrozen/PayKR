## 2. 변경 전후 — 구조별 예상(실측 아님)
일 방문 5,000, 지도 SDK 1건/방문, 키워드 20건/방문 가정:

| 구조 | 지도 SDK | 키워드 검색 | 전체 카카오 호출/일 |
|---|---|---|---|
| 기존 예시 | 5,000 | 100,000 | 105,000 |
| 지도 엔진만 교체(MapLibre) | 0 | 100,000 | 100,000 (~4.8%↓) |
| 지도 교체 + 검색 5건/방문 최적화 | 0 | 25,000 | 25,000 (~76.2%↓) |

위 수치는 설명용 가정이며 **실측이 아니다**. 실제 SDK 계수·검색 횟수·추가 호출·타일 공급·프록시
비용에 따라 달라진다. 호출량 절감률과 실제 청구 금액 감소율은 구분한다.

## 3. 실제 검색 호출 계측 결과(mock provider)
`tests/map-ui.test.mjs`의 계측:
- 단일 배치: 호출 12회, 동시 최대 4회.
- 전체 순회(autoScan): 165개 브랜드, 14배치, 브랜드별 최대 3페이지 → 배치 수 고정.

카카오 대시보드 실측치가 없으므로 실전 호출량·비용은 **추정과 분리**한다. 운영자 대시보드
수치를 확보하면 본 문서를 갱신한다.

## 4. 절감 원칙
- All/이 지역 검색 등은 전체 순회가 필수이며, 결과 품질 유지를 위해 검색을 축소하지 않는다.
- 중복 요청 병합, 세대 취소, 지도 드래그 중 요청 금지, 중복 페이지 방지, 오래된 응답 무시,
  429/쿼터 시 즉시 중단·안내, 무한 재시도 금지.
- MapLibre 모드에서는 카카오 지도 SDK 요청이 0임을 네트워크로 검증한다.
